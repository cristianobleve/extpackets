Design ultra-pulito ed elegante ispirato ai prodotti Apple TV+ e Vercel, privo di effetti rumorosi o stile "Cyberpunk". Supporto nativo ai temi preimpostati (Obsidian, Cinema, Nordic, Monochrome).

🎨 Preset Temi integrati

Scegli un tema elegante o personalizza i colori via CSS: 

const player = new ExtPlayer('#player', {
  src: 'https://vjs.zencdn.net/v/oceans.mp4',
  title: '🌊 Ocean Wildlife Showcase',
  
  // Temi Integrati: 'obsidian' | 'cinema' | 'nordic' | 'monochrome'
  theme: 'obsidian',
  
  loop: true,
  ambientGlow: false
});

// Cambia tema dinamicamente:
player.setTheme('cinema');
