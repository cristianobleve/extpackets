# Release History

### `v1.0.3` (Latest)
- 🖤 **Geometric Dark Monochrome Theme**: Set `theme: 'monochrome'` as default theme with sharp `6px` radiuses and pitch-black (`#000000`) player background.
- 📚 **Comprehensive Documentation**: Complete Mintlify documentation repository in English.
- 📦 **NPM & GitHub Release**: ExtPlayer published to `@cristianobleve/player@1.0.3`.

### `v1.0.2`
- 🌐 **Universal Video Provider (`VideoProviderPlugin`)**: Added automatic embed resolution for YouTube, Vimeo, Dailymotion, Twitch, and Cloud Storage.
- 🖼️ **Auto-Poster Frame Extraction**: Automatically extracts video snapshot if poster is omitted.

### `v1.0.1`
- 🛠️ **UMD Script Tag Fixes**: Fixed global `window.ExtPlayer`, `window.ExtAudio`, `window.ExtLightbox`, `window.ExtUploader` window bindings for browser `<script>` usage.

### `v1.0.0`
- 🚀 **Initial Release**: Initial release of the 4 ExtPackets monorepo packages (`player`, `audio`, `lightbox`, `uploader`).
