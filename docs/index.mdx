## Overview

**ExtPackets** is a modular web media ecosystem built with zero-dependency TypeScript, ultra-clean CSS design systems, and seamless CDN/NPM integrations. 

Each component in the suite is built from the ground up to deliver a minimalist, luxury aesthetic (dark slate, geometric sharp radiuses, subtle borders, and smooth micro-animations).

## Key Highlights

- ⚡ **Zero External Heavy Dependencies**: Lightweight, lightning-fast execution and small footprint.
- 🎨 **Shadcn & Monochrome Dark Design**: Dark mode aesthetic with sharp geometric radiuses (`6px`), high-contrast white accents, and polished UX.
- 🌐 **Universal Media Resolution**: Native support for direct MP4, YouTube, Vimeo, Dailymotion, Twitch, and Cloud Storage providers.
- 📦 **Dual Dist Distribution**: Import via NPM (`import ExtPlayer from '@cristianobleve/player'`) or drop single `<script>` tags via CDN.
